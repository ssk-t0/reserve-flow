## 概要

**ReserveFlow** は、小規模店舗・サービス業向けの予約管理・顧客管理・スタッフ管理を一元化したウェブ管理システムのデモアプリです。  
バックエンドや外部認証サービスを使わず、**Next.js + localStorage のみ**で完全動作するため、セットアップなしにすぐデモできます。

---

## 作成目的

フロントエンド〜フルスタック開発の実務スキルをポートフォリオとして示すために制作しました。  
実際の業務システムで求められる要件（CRUD・検索・フィルタリング・CSV エクスポート・レスポンシブ対応）を意識して設計しています。

## 主な機能

### ダッシュボード
- 本日の予約数・今月の売上・顧客数・稼働スタッフ数の KPI カード表示
- 本日の予約一覧・直近の予約一覧
- 月別売上グラフ（CSS 棒グラフ）
- スタッフ別予約数グラフ

### 予約管理
- 予約の作成・編集・削除（モーダル UI）
- ステータス管理：予約済み / 来店済み / キャンセル / 無断キャンセル
- 顧客名・サービス名検索、日付・ステータス・スタッフ絞り込み
- CSV エクスポート

### カレンダー
- 月間カレンダー表示（ライブラリ不使用）
- 日付クリックでその日の予約詳細をサイドパネル表示

### 顧客管理
- 顧客の登録・編集・削除
- タグ管理：VIP / 新規 / リピーター / 要注意
- 顧客詳細モーダル（予約履歴・対応メモ）

### スタッフ管理
- スタッフの登録・編集・削除（管理者のみ表示）
- カード型レイアウトで今月の予約数・売上を一覧表示
- スタッフ別予約履歴の確認

### 売上レポート
- 月別売上・来店数・平均単価・キャンセル率の集計
- 月別推移グラフ・スタッフ別ランキング・サービス別内訳
- CSV エクスポート

### 設定
- 店舗名・営業時間・定休日・予約単位・キャンセル期限の設定
- localStorage へ自動保存

## セットアップ方法

```bash
# リポジトリをクローン
git clone https://github.com/your-username/reserveflow.git
cd reserveflow

# 依存パッケージをインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くと自動的にサンプルデータが投入されます。

### Vercel へのデプロイ

```bash
npm run build  # ビルド確認
```

Vercel ダッシュボードでリポジトリを連携すると自動デプロイされます。環境変数の設定は不要です。

## デモの見方（採用担当者向け）

1. **ログイン画面**でデモアカウントボタンをクリック → 自動入力されてすぐログインできます
2. **ダッシュボード**で KPI・本日の予約・グラフを確認します
3. **予約管理**で「予約を追加」ボタンからモーダルを開き、新規予約を作成してみてください
4. **カレンダー**で日付をクリックするとその日の予約が右パネルに表示されます
5. **顧客管理**でVIPやリピーターなどタグで絞り込み、顧客名をクリックして詳細を確認します
6. **売上レポート**で月を切り替えると集計が変わります。CSVエクスポートも動作します
7. **スタッフ管理・設定**は管理者アカウントでのみ表示されます

## 工夫した点

### UX・デザイン
- 管理画面として実務感が出るよう、SaaS ライクな清潔感あるデザインを採用
- ステータスをカラーバッジで視覚的に区別（予約済み=青、来店済み=緑、キャンセル=グレー、無断=赤）
- ホバーで操作ボタンが出現するテーブル UI でスッキリした見た目を維持
- 空データ時には適切なイラスト付きメッセージを表示

### 技術
- `useCallback` / `useMemo` で不要な再計算・再レンダリングを最小化
- `localStorage` アクセスを `typeof window` で SSR セーフに制御
- TypeScript の `as const` / ユニオン型でタイプセーフな状態管理
- `any` を一切使用せず、厳格な型定義を徹底

### 機能
- 管理者とスタッフでサイドバーのメニューを動的に出し分け
- CSV エクスポートで BOM 付き UTF-8 を出力（Excel での文字化け防止）
- 初回起動時に現在日時を基準にしたリアルなサンプルデータを自動投入

### レスポンシブ
- モバイルではサイドバーをオーバーレイメニューに切り替え
- テーブルは重要度の低いカラムをモバイルで非表示にし崩れを防止
